# BookSpace — онлайн-бібліотека з пошуком за жанрами

**Варіант 12 | Лабораторна робота «Документація в ІТ»**

## Про проєкт

**BookSpace** — навчальний концепт онлайн-бібліотеки, у якій читач може знаходити книжки за назвою, автором і жанром, переглядати інформацію про них та зберігати цікаві видання в обране.

Проєкт вирішує просту проблему: коли книжок багато, користувачу складно швидко знайти потрібну. Пошук і фільтри допомагають скоротити час на вибір.

> **Статус:** це демонстраційний проєкт для вивчення документації. У репозиторії містяться Markdown-документи та макет інтерфейсу, але немає готового сайту чи серверної частини. Приклади API є вигаданими.

## Основні можливості

| Функція | Опис |
| --- | --- |
| Каталог книжок | Перелік видань із назвою, автором, жанром і роком виходу |
| Пошук | Пошук книжки за назвою або автором |
| Фільтр жанрів | Вибір фантастики, детективів, пригод та інших категорій |
| Картка книжки | Коротка інформація про обране видання |
| Обране | Збереження книжок у власний список після входу в обліковий запис |

## Для кого призначений

- Для студентів, які шукають художню та навчальну літературу.
- Для читачів, які хочуть відкривати книжки певного жанру.
- Для бібліотекарів, яким зручно мати структурований електронний каталог.
