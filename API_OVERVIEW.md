# Огляд API — BookSpace

## Загальна інформація

Нижче наведено **вигадані приклади REST API** майбутньої онлайн-бібліотеки. Запити та відповіді показують можливу структуру обміну даними; справжнього сервера за цими адресами немає.

**Приклад базової адреси:** `https://api.bookspace.example/v1`  
**Формат даних:** JSON (`Content-Type: application/json`)

У книжки є ідентифікатор `id`, назва `title`, автор `author`, жанр `genre`, рік видання `year` та ознака наявності `available`.

## 1. GET /books — пошук книжок

Повертає перелік книжок. Необов'язкові параметри: `genre` — жанр, `search` — слово в назві або імені автора.

**Запит:**

```http
GET /v1/books?genre=fantasy&search=ліс HTTP/1.1
Host: api.bookspace.example
Accept: application/json
```

**Відповідь — 200 OK:**

```json
{
  "total": 1,
  "books": [
    {
      "id": 101,
      "title": "Ліс між світами",
      "author": "Ірина Левченко",
      "genre": "fantasy",
      "year": 2023,
      "available": true
    }
  ]
}
```

## 2. GET /books/{id} — перегляд однієї книжки

Повертає інформацію про книжку за її ідентифікатором.

**Запит:**

```http
GET /v1/books/102 HTTP/1.1
Host: api.bookspace.example
Accept: application/json
```

**Відповідь — 200 OK:**

```json
{
  "id": 102,
  "title": "Код майбутнього",
  "author": "Андрій Шевчук",
  "genre": "science-fiction",
  "year": 2024,
  "available": true,
  "description": "Науково-фантастична історія про технології майбутнього."
}
```

**Якщо книжки немає:** `404 Not Found`.

```json
{
  "error": "BOOK_NOT_FOUND",
  "message": "Книжку з таким id не знайдено"
}
```

## 3. POST /favorites — додавання до обраного

Зберігає книжку до списку обраного для авторизованого користувача.

**Запит:**

```http
POST /v1/favorites HTTP/1.1
Host: api.bookspace.example
Authorization: Bearer DEMO_TOKEN
Content-Type: application/json

{
  "book_id": 101
}
```

`DEMO_TOKEN` — умовне значення для прикладу, не справжній ключ доступу. Користувач визначається за токеном.

**Відповідь — 201 Created:**

```json
{
  "favorite_id": 501,
  "book_id": 101,
  "status": "added"
}
```

Якщо користувач уже додав книжку, сервер може повернути `409 Conflict`.

## Коди відповідей

| Код | Значення | Приклад ситуації |
| --- | --- | --- |
| `200 OK` | Запит виконано | Список книжок успішно отримано |
| `201 Created` | Створено новий запис | Книжку додано до обраного |
| `400 Bad Request` | Некоректні параметри | Передано неправильний `book_id` |
| `401 Unauthorized` | Потрібна авторизація | Немає токена для додавання в обране |
| `404 Not Found` | Ресурс не знайдено | У каталозі немає книжки з таким `id` |
| `409 Conflict` | Конфлікт даних | Книжка вже є в обраному |
| `500 Internal Server Error` | Помилка сервера | Непередбачена помилка обробки |

## Примітка

Усі ідентифікатори, назви книжок, адреси та відповіді наведено лише для демонстрації технічної документації. Вони узгоджені з функціями, описаними у [README.md](README.md).
